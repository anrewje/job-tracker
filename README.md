# 🎯 Job & Internship Tracker (IT Career Tracker)

Интерактивный веб-трекер для поиска работы и производственной практики по направлению **«Сетевое и системное администрирование / Junior DevOps»**.

## 🚀 Возможности
- **50 проверенных компаний:** база компаний Сахалинской области (Южно-Сахалинск) + ведущие российские хостинги и облачные провайдеры (удаленно).
- **База данных SQLite (`tracker.db`):** автоматическое сохранение состояний откликов, статусов ответов и заметок. Данные не пропадают при перезапуске ПК.
- **Цветовая индикация статусов:**
  - `✅ Да (Ответили / Одобрено)` — строка подсвечивается зеленым цветом.
  - `❌ Нет (Отказ)` — строка подсвечивается красным цветом.
  - `⚠️ Нет такой почты / Ошибка` — строка подсвечивается оранжево-желтым цветом.
  - `☑️ Отправлено` — мягкая синяя подсветка.
- **Способы отправки:** фиксация канала отклика (Email, сайт компании, hh.ru, Telegram) + поле для быстрых заметок.
- **Добавление своих компаний:** форма для внесения любых работодателей вручную.
- **Фильтрация и поиск:** выборка по региону (Сахалин / Удаленка), отправленным письмам и ошибкам доставки.
- **Экспорт в Excel (.csv):** выгрузка актуальной таблицы в один клик.

## 🛠 Стек технологий
- **Backend:** Python 3 (встроенный `http.server`), `sqlite3`
- **Frontend:** HTML5, CSS3 (Modern Dark Theme, Sticky Header), Vanilla JavaScript (Fetch API, LocalStorage fallback)
- **База данных:** SQLite 3

## 💻 Быстрый старт локально

1. Склонируйте репозиторий:
```bash
git clone https://github.com/anrewje/job-tracker.git
cd job-tracker
```

2. Запустите сервер с базой данных:
```bash
python server_with_db.py
```
*(Или запустите файл `start_tracker_db.bat` двойным кликом на Windows)*

3. Откройте в браузере:
👉 **http://localhost:3031/tracker.html**
